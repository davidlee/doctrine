## Why not a no-flag subverb

The scope card's phrasing — *"`CPT`'s empty facet becomes expressible as a
subverb with no flags rather than 30 refusals"* — was written while `OQ-4` was
still open, and reads the empty facet as a shape to be *expressed*.

Once [[DEC-172]] rules the emptiness designed, there is nothing to express. A
concept's content is its prose body, and `knowledge edit CPT-001` already
reaches every part of a concept a caller can change: title, tags, body.

A subverb accepting no flags would be a command with no valid invocation. Every
use of it is a mistake, which makes it a worse surface than its absence.

## The refusal is nearly free

Per-kind subverbs *relocate* the kind check rather than remove it — the id
prefix already resolves the kind, so `knowledge edit decision ASM-003` has to be
refused whatever else is true. That message is being built regardless.

The concept arm is one more row on it:

- wrong subverb for this id — *"`ASM-003` is an assumption; use `knowledge edit
  assumption`."*
- no subverb exists for this kind — *"concept records carry no facet fields; use
  `knowledge edit CPT-001`."*

Both teach the caller the right command, which is the standard SL-249's scope
card set for the mismatch refusal.
