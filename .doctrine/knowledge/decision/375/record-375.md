Install writes framework gitignore entries into a delimited managed block in the root .gitignore (# >>> doctrine (managed) / # <<< doctrine), rewritten wholesale each install: the manifest's runtime-state entries, one glob per [framework] canon root, and one line per link install writes into a shared harness dir. Prune drops a link and its line together; dedup is intrinsic. Lines outside the block are user-owned and never touched — a user can gitignore less by following the block with ! negations, which survive re-install because the block is rewritten in place. Skills delegated to npx skills (.agents/skills/<id>) get derived lines but are not pruned (npx owns their lifecycle), disclosed. Hymns are never ignored. Legacy loose lines from older installs are left (migration non-goal). This repo's .gitignore carries the generated block; a parity test asserts every derived entry is present there, covering the gap the .doctrine-only classification gate leaves. Rejected: per-shared-dir globs (would ignore the user's own files in .claude/skills etc.); a hand-kept entries list (STD-001).
