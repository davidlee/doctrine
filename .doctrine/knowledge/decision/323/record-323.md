The codex `[mcp_servers.doctrine]` entry emits `command = "sh"`, `args = ["-c", "exec \"${DOCTRINE_BIN:-doctrine}\" serve --mcp"]` and `env_vars = ["DOCTRINE_BIN"]`.\n\nThe wrapper is required because codex neither interpolates `${VAR:-default}` in `command` (probe-verified on codex 0.155.1: it execs the literal string) nor forwards the parent environment to an MCP child except through `env_vars`. Inside a shell both behaviours return, so the entry carries no machine path (POL-002 facets 1-2) while the `DOCTRINE_BIN` override survives.\n\nThe `sh` dependency must be DECLARED (POL-002 facet 3) as a baseline requirement named in README/install documentation, or a feature-scoped opt-in with a descriptive absence message. Silent acquisition of the shell is the prohibited form.\n
