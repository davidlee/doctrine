# DEC-160: Conformance suite ships behind a verb with a test caller

**Two verbs on `doctrine-control`, built but not released.** The workspace split is cheap precisely because nothing new ships (DEC-153 § The cheap path); the distribution contract — nix `srcWithDist`, binstall asset name, `install.sh` and `release.yml` — is a close-time Follow-Up for whichever slice first releases the binary (risk R5). So the binary is reachable from the build tree only, matching the scope's "tested machinery sitting beside the incumbent arms, unused". `provision` is the verb consuming contract resolution, the refinement algebra, capacity, layout, and the backend. A transaction `show` verb is deliberately omitted: nothing operates this yet and tests inspect the returned transaction directly.

**The conformance suite lives in the product behind `backend verify`, with the integration test as a second caller.** One conformance module, two callers: the test drives it so CI asserts *admitted* on a Linux host with bubblewrap, and the verb drives it for the on-host verdict, where not-admitted is a nonzero exit with structured output. A `tests/`-only suite was rejected because DEC-156 requires an unavailable backend to report not-admitted rather than skip green, and a skipped or early-returning `cargo test` reports green — the exact failure DEC-156 was written against. The verb is also the descriptive absence path POL-002 facet 3 asks for on bubblewrap. Product weight stays small because probe payloads are argv strings, not compiled helpers or embedded assets.

**The nine properties are table-driven over a fixture helper.** One helper takes a payload and a property-removal and returns exit status with captured output; each property is then a `(name, payload, property-removed)` row. This is where the Rust-versus-shell cost actually concentrates — process orchestration is the one act materially more verbose than bash, and the repetition across nine probes and nine controls is what compresses. The typed parse, validation, duplicate rejection, canonical hash, and subset algebra are all cheaper in Rust than they would be in shell, and a shell arm would carry a second language boundary and its own gate. Generated shell is correct for what runs *inside* the capsule and wrong trusted-side, where the typed refusals, the canonical hash, and the read-once invariant live and where generated shell would reintroduce quoting hazards on a security boundary.

**Nested bubblewrap works in the development jail** — verified this session: `bwrap --ro-bind / / --dev /dev --proc /proc --tmpfs /tmp --unshare-all -- /bin/sh -c 'echo nested-ok'` succeeds inside the jail. The executed suite therefore runs in the normal development environment, and neither dispatch nor CI needs a special arrangement for it.

**Caveat on the nested-bubblewrap claim above.** It was re-measured while remediating `RV-346` round 3 and it holds in this project's jail — `--unshare-all`, `--unshare-net` alone, and the explicit non-network unshare set all succeed one level down. What it does not cover is a *third* layer. `F-20` reported the same profile failing with `Failed to create NETLINK_ROUTE socket: Operation not permitted` from inside an agent sandbox wrapping the jail, whose filter denies the socket bubblewrap opens to bring up loopback in a fresh network namespace. The specific claim — that this project's jail cannot run the suite — did not survive its positive control and is withdrawn. The general one stands and is worth recording here rather than only in the design: any confinement layer that denies network-namespace setup makes the network-posture probe, and therefore admission, impossible on that host. "Neither dispatch nor CI needs a special arrangement" is true of the arrangements measured, not of every runner.

**End to end terminates at the suite.** Provision a capsule, execute through the backend primitive, and observe the nine properties, the five-axis freshness distinctness (DEC-157), REQ-449's refusal branches, and REQ-461's two tiers. Harvest and admission are Non-Goals, so there is no further downstream to reach.
