The trial lives in `crates/doctrine-jev` (doctrine-control precedent: own deps, `publish = false`, outside `default-members`, named `just` recipe). No path dependency on the root lib: its export set is curated and asserted by `tests/architecture_layering.rs`, and widening it would touch shipped surface. Corpus facts come through subprocess boundaries against the exported snapshot: `git` (archive, log), `doctrine search -p` (arm A pool), `doctrine catalog scan --root` (canonical id, kind and path per entity - so no local prefix table). Caveat: `catalog scan` is a debug verb with no stable output contract; acceptable for a trial, an adoption slice must re-ground it. Subcommands: `labels` (one-time committed fixture), `probe` (~10 live calls), `rank SL-NNN --arm A|B|C`, `eval`; every command is dry-run unless `--live --cap-usd N`. HTTP via `reqwest` with rustls and no default features, keeping the crane `--workspace` build hermetic.
