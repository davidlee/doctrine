Append-only [[variance]] table in commitment-ledger.toml: {commitment, class = realisation|intent, change, basis (DEC / consult / user turn), phase (or "plan" before execution)}. A commitment's quote is never edited; variances stack. realisation = how it is met changed, needs only a recorded basis; intent = what must be true changed, always needs the user or a design revision (thin form of RFC-026 G15 intent/realisation split; SL-258 OQ-1 envelope may refine it). Lock→planning: extraction defects go back to /design; a different realisation chosen at planning is a variance with phase = plan. /execute and /consult get a one-line pointer to record variances; /audit reads the table.
