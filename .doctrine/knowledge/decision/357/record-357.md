Memories are neither candidates nor labels in this trial. They are ~3% of research.md citations (130 memory-key vs 4,700 entity-id matches, 2026-09-29), and `doctrine search` does not index them, so including them would give arm C candidates arm A can never see and confound the pool comparison. Memory labels are dropped and the count disclosed per slice (STD-003). A memory arm, pairing `doctrine memory search` with Jev, is a candidate follow-up.
