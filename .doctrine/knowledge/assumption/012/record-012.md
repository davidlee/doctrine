The design run mints RVs via `review::mint_review` (`src/commands/design.rs:1487`), which skips `resolve_review_root`. That is safe only because `design apply` has no MCP tool and the CLI `worker_guard` refuses it under `DOCTRINE_WORKER` — the same predicate SL-269's review admission uses. If a design-run MCP tool is ever added, it must apply the worker predicate before minting. Project rule: MCP tools exist only where they give markedly better agent UX than the CLI; `design apply` already takes one JSON payload.
