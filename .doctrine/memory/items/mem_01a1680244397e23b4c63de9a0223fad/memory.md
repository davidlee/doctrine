Two install facts that matter for anything provisioning a worktree (SL-285):

- **Install marker.** `read_install_marker` (`src/install.rs:3476`) reads the
  checkout's own `.doctrine/state/install.toml`, else — for a linked worktree,
  which never receives `.doctrine/state/` — the main worktree's marker. A fork
  does not report "not installed" for lack of its own marker.
- **Hook command form.** `CommandForm` (`src/boot.rs:1105-1119`): a *tracked*
  file gets `${DOCTRINE_BIN:-doctrine} <args>` (Portable); a *gitignored* one
  gets `<abs exec> <args>` (Baked). Codex hooks are always Baked
  (`src/boot.rs:2854`); claude Local settings are Baked (`:594-599`). Ignored
  wiring regenerated by one binary pins that binary's absolute path.
