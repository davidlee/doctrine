Dispatch worktrees cannot straightforwardly run a faithful live-agent evaluation of skill edits because installed skills resolve from github:origin/main rather than the candidate worktree. For a slice changing plugins/doctrine/skills/**, use deterministic asset/install tests before closure and schedule live behavioural measurement immediately after the changes land. Only gate pre-close on a live run when the harness has an explicit, verified way to load the candidate worktree's skill source.
