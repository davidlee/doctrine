# A new rule is not settled until it has been applied to its whole population

A ruling that fixes a real defect can smuggle in a second, unargued ruling as a
**qualifier** on the fix. It survives review because everyone reads the sentence
for the part that was contested.

**SL-233 RV-325, rounds 3 → 11.** Round 3 ruled: *verification strength is an
orthogonal axis, not the sorting rule* — adopted precisely so mechanically
unverifiable but genuinely mandatory acts had somewhere honest to sit. Round 10
correctly ruled that classification is a property of an obligation's text, not of
a run, and wrote an authoring gate: *every 2a step states a truthful completion
condition **and checkable in run state***. The italic clause was never argued. It
silently reversed round 3, and ten rounds of re-reading the sentence did not
surface it.

**Applying the rule is what surfaced it, not reading it again.** Working the gate
over all nine obligations instead of the one worked exemplar produced two
mechanical reductios in minutes: it demoted the two acts round 3 protected *by
name*, and it condemned four of five *already shipped* steps.

## How to apply

- **Before believing a new rule, run it over its whole population** and record a
  row per member. A rule demonstrated on one exemplar has not reproduced its own
  assignments — that is not pedantry, it is the only cheap falsifier the rule has.
- **The population includes what already shipped**, not only what the current
  change relocates. Excusing a whole asset on the strength of one of its members
  is how the gap here survived.
- **When two rulings collide, check which one was *argued*.** A qualifier riding
  a correct ruling loses to an explicit prior ruling on the same axis; that is an
  adjudication on the record, not a preference.
- **Then sweep per site, not by find-and-replace.** The same withdrawn clause was
  load-bearing in one other place (a reword arm, where dropping it would let a
  step escape a signal by becoming uncollectible). See
  [[mem.pattern.review.claim-withdrawal-sweep-repo-wide]].

**Why:** the expensive failure mode is not a wrong rule — it is a rule everyone
agrees with that has never been made to touch the set it governs. Cost here: six
rounds to find the first error, and it took *applying* the fix to find the second.
