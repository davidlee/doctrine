# RFC-018: Claude harness field notes: empirical findings and design-artifact map

## Context

Doctrine's dispatch / worktree / workflow machinery runs *on top of* the Claude
Code harness, whose spawn, isolation, hook, commit, and MCP semantics are only
partially documented and shift across releases. Repeatedly, correctness turns on
an **empirical** property of the harness (the Workflow primitive strips the
`Agent` tool; a linked worktree's `.git` is RO in the jail; `SubagentStop` fires
tree-intact) that no spec asserts and that cost real probe-sessions to establish.

Those findings are already durable in the memory corpus — but scattered across
~35 `mem.*` items and several RFC case-notes, discoverable only by someone who
knows the key. This RFC is **not** a decision and asserts **no** canon. It is a
**field notebook**: a curated, grouped index of what we have empirically learned
about the harness, plus a map of the significant design artifacts for the four
subsystems that ride it (dispatch, workflow, worktree, subagents).

Memory items remain source-of-truth; the entries below are one-line pointers, not
copies. Cite the `mem.*` key or artifact id, then read it via `doctrine memory
show` / `doctrine <kind> show`.

## Discussion

### 1. Empirical findings — the Claude Code harness

Grouped by seam. Each row: **finding → `mem.*` key**. Read the item for proof,
probe id, and consequence.

#### 1a. Subagent spawning & the `Agent` tool

| Finding | Memory |
|---|---|
| Workflow runtime **unconditionally strips `Agent`** from every `agent()` leaf — even a `Tools:*` def; leaves cannot nest-spawn. Also strips Grep/Glob, injects `StructuredOutput`. | `mem.fact.claude.workflow-strips-agent-tool` |
| Frontmatter `isolation:` **is** honored for nested (Agent-tool) subagent spawns. | `mem.fact.claude.frontmatter-isolation-honored-nested` |
| A `dispatch-worker` Agent spawn needs `isolation:worktree` explicitly — omission runs in-place in the coord tree, no fork. | `mem.fact.dispatch.claude-arm-spawn-needs-isolation-worktree-flag` |

#### 1b. `isolation:worktree` mechanics — base, minting, teardown

| Finding | Memory |
|---|---|
| `WorktreeCreate` plugin hook fires (2.1.198); `-w` bypasses it. | `mem.fact.claude.worktreecreate-hook-fires` |
| Teardown (auto-remove) is **conditional on** the WorktreeCreate hook having run. | `mem.fact.claude.worktree-remove-auto-teardown` |
| WorktreeCreate payload is minimal — **no type, no target path, no base**; use SubagentStart to stamp identity. | `mem.pattern.dispatch.claude-worktreecreate-payload-minimal-no-type-no-path` |
| WorktreeCreate payload `cwd` = session working-dir → an orchestrator-controlled **per-spawn channel**. | `mem.fact.dispatch.worktreecreate-cwd-channel` |
| `CLAUDE_PROJECT_DIR` is present in the worktree-subagent hook env. | `mem.fact.claude.project-dir-in-worktree-subagent-hook-env` |
| Agent `isolation:worktree` base = the spawning session's local HEAD (`baseRef=head`) — controllable by **placement**, not ref-redirect. | `mem.pattern.dispatch.claude-isolation-worktree-forks-orchestrator-session-head` |
| …restated: base is session-root main and **opaque** — not the coord-tree tip. | `mem.pattern.dispatch.claude-isolation-worktree-base-session-root-opaque` |
| Agent worker worktree base is **uncontrollable** (tracks origin/main) → run dependent serial phases inline on the coord tree. | `mem.pattern.dispatch.claude-agent-worktree-forks-origin-main-tracking-ref` |
| Agent worker commit **integrates onto the parent branch**, not an isolated fork. | `mem.pattern.dispatch.claude-agent-worktree-integrates-commit-onto-parent` |
| Agent worktree is **harness-born, not fork-provisioned** — a creation hook must provision+stamp (WorktreeCreate, fail-closed). | `mem.pattern.dispatch.claude-agent-worktree-not-fork-provisioned` |
| Fork path: worktree **persists** + footer carries `worktreePath` — proven live. | `mem.fact.dispatch.claude-fork-path-persist-footer-proven` |
| Workflow `agent(isolation:worktree)` **fires** the WorktreeCreate hook; payload cwd = session working-dir. | `mem.fact.workflow.agent-worktree-fires-create-fork-hook` |
| Workflow `agent(isolation:worktree)` mints the confined fork **AT the armed base** (positional arming), not cwd HEAD. | `mem.fact.workflow.confined-fork-mints-at-armed-base` |

#### 1c. Commit path & worker identity

| Finding | Memory |
|---|---|
| A Workflow `isolation:worktree` leaf **cannot commit in the jail** — RO shared `.git`, and it is not a registered `DispatchRecord` so `worker_commit` refuses. Both commit paths closed. | `mem.fact.claude.workflow-leaf-cannot-commit` |
| Claude-arm worker stamps a worker marker on the coord tree and commits onto the coord branch (expected). | `mem.pattern.dispatch.claude-arm-isolation-fallback` |
| Worker identity via **SubagentStart** hook, not a SessionStart env-seam. | `mem.pattern.dispatch.claude-subagentstart-worker-identity` |
| Claude dispatch worker **cannot get per-worktree env** via hooks. | `mem.fact.dispatch.claude-worker-no-per-worktree-env` |

#### 1d. Hooks — PreToolUse, SubagentStop, confinement

| Finding | Memory |
|---|---|

| SL-182 PreToolUse jail walls **only Bash/Edit/Write**; other tools pass through. | `mem.fact.dispatch.pretooluse-wall-mediates-write-tools-only` |
