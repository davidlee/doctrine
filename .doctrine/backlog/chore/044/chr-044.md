
## Context

Surfaced by the SL-219 PHASE-01 dispatch worker (claude arm, 2026-07-16).

`doctrine check commit` cannot go fully green inside a marked worker fork:
~36 e2e test binaries spawn the built `doctrine` binary for authored writes
(`adr status`, `slice new`, `backlog new`, `install`, …), which the
worker-mode guard correctly refuses (`worker fork (signal: marker): refusing
authored write`).

The designed skip helper (`skip_under_worker_marker`,
`tests/e2e_adr_cli_golden.rs`) keys on the `DOCTRINE_WORKER` env var, but the
claude spawn arm marks the worktree via the marker FILE without propagating
the env — the skip never engages, and most e2e write goldens have no skip
helper at all. Workers burn tokens diagnosing environmental red as if it were
their delta.

## Options

- Propagate `DOCTRINE_WORKER` into claude-arm worker envs (hook-side), or
- extend the skip helper to probe the marker file, and roll it out across the
  e2e write goldens.
