This is the last claim, and the only one about the design itself rather than
about the process that produced it. Everything before it asks whether the work
was done. This asks whether the result is right.

If it were the sum of the conditions before it, it would not need a person and
it would not be here — the machine can already tell you every obligation was
met. It exists because a design can satisfy all of them and still be the wrong
design, and there is no check anywhere capable of catching that. Only a reader
willing to say no.

Which is the whole cost of giving it lightly. Nothing downstream asks the
question again; the design becomes the thing other work is built against, and
every later discovery that it was wrong is paid for at implementation prices.
This is the last point at which *no* is cheap.
