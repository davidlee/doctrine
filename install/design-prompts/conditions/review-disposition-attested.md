A review that produces findings and no decisions has spent somebody's effort
and bought nothing. It is worse than that: it leaves behind a record that
reads like diligence, which is how a design ends up trusted for a reason that
was never true.

That is why there are two doors here instead of one. The second exists because
a review is not always the right use of the moment, and a process that
pretends otherwise gets satisfied with an empty gesture rather than an honest
skip. The mistake is reading that door as the cheap one. It is cheaper in
effort and not in exposure — the reason given is kept, it stays attached to
the design, and it is read by whoever is deciding later whether to trust this
work.

Neither door rewards a pass that was run and then quietly set aside. That
outcome is the one both are shaped to make unavailable.
